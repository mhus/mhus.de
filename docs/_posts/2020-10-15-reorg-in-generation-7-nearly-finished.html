The generation 7 shows massive reorganisations and reimplementations. After renaming repository names (moved the 'cherry' prefix to 'mhus') the reorg is finished and the sources are ready for a more stable generation 8. Generation 8 will add new features to work with none OSGi services in cloud environments.

Actual changes:

  • cherry-reactiive -> mhus-reactive
  • cherry-vault -> mhus-vault
  • cherry-web -> mhus-web
  • mhus-osgi-cluster -> mhus-cluster
